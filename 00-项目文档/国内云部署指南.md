# 国内云服务器部署指南（无银行卡版）

> 目标：把心理测试广场部署到国内云服务器，获得公网 IP，别人通过 `http://你的服务器IP:3000` 访问。
> 前提：实名认证（身份证 + 手机号），**不需要银行卡**。

---

## 第 1 步：注册 + 实名认证 + 领服务器

任选一家（新用户通常有免费试用/优惠）：

- **阿里云**：轻量应用服务器 → https://www.aliyun.com/product/swas
- **腾讯云**：轻量应用服务器 → https://cloud.tencent.com/product/lighthouse

操作：
1. 注册账号 → 完成**实名认证**（身份证 + 手机号，人脸识别）。
2. 选一台「轻量应用服务器」，**地域选离你近的**（如华东/华南），系统镜像选 **Ubuntu 22.04** 或 **Debian 12**。
3. 付款/领取（免费试用档通常 0 元）。记下服务器的 **公网 IP**、**登录用户名**（Ubuntu 是 `root` 或 `ubuntu`）和**密码/密钥**。

---

## 第 2 步：连接服务器（SSH）

在你自己电脑上（Windows 自带）：

```powershell
ssh root@你的服务器IP
```

> 提示输入密码时粘贴第 1 步设置的密码。也可以用 **WinSCP**（图形界面，上传文件更方便）。

---

## 第 3 步：安装 Docker（含国内镜像加速）

连上服务器后，逐条执行：

```bash
# 安装 Docker（官方脚本）
curl -fsSL https://get.docker.com | sh

# 配置国内镜像加速（解决拉取慢/失败）
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json >/dev/null <<'EOF'
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://dockerproxy.com"
  ]
}
EOF

sudo systemctl restart docker
```

> 如果拉镜像仍失败，去阿里云/腾讯云控制台搜「容器镜像服务」，按它的「镜像加速器」地址替换上面的 mirrors。

---

## 第 4 步：上传代码到服务器

因为 GitHub 被墙，走「本地上传」最稳。推荐用 **WinSCP**（图形界面）：

1. 下载 WinSCP → 连接服务器（IP + 用户名 + 密码）。
2. 在服务器上建目录 `/root/psychlab`。
3. 把本机 `E:\my project` 下**这些内容**拖进去（不用 `.git`、`.obsidian`、`node_modules`、`server/.env`）：

```
Dockerfile
docker-compose.yml
.dockerignore
index.html
assets/
big-five/  cognitive-bias/  decision-style/
eq-assessment/  moral-dilemma-lab/  values-sort/
user-center/
server/
```

> 命令行版：本机 PowerShell 执行
> `scp -r . root@你的IP:/root/psychlab`（会多传一些无关文件，没关系）

---

## 第 5 步：启动服务

```bash
cd /root/psychlab

# 先改密码！编辑 docker-compose.yml 里两处「改成你自己的…」
nano docker-compose.yml

# 一键构建并启动（数据库 + 应用，自动迁移+播种）
docker compose up -d --build

# 查看日志，看到 "PsychLab API running" 即成功
docker compose logs -f app
```

> 首次构建要拉镜像 + npm install，约 3–8 分钟，耐心等。

---

## 第 6 步：开放防火墙端口（重要！）

国内云有「**安全组**」防火墙，默认不开放 3000 端口，不开放的话外面访问不到。

- 阿里云：控制台 → 你的服务器 → **安全组** → 添加入方向规则：**协议 TCP，端口 3000，来源 0.0.0.0/0**。
- 腾讯云：控制台 → 轻量应用服务器 → **防火墙** → 添加规则：**TCP 3000，允许**。

---

## 第 7 步：验证

1. 本机浏览器开 `http://你的服务器IP:3000` → 应能看到首页。
2. 开 `http://你的服务器IP:3000/api/health` → 应返回 `{"status":"ok"}`。
3. 注册一个账号 → 跑个测试 → 看历史。
4. 把这个 IP 地址发给别人。

---

## 常见问题

- **访问超时**：90% 是第 6 步安全组没开 3000 端口。
- **docker compose 找不到命令**：老版本用 `docker-compose`（带横杠）代替 `docker compose`。
- **想用 80 端口（不用带 :3000）**：未备案时国内 80 端口常被限制，先用 3000 稳。以后备案了再改。
- **想长期稳定运行**：`docker compose` 里已设 `restart: unless-stopped`，服务器重启会自动拉起。
- **换数据库密码后要重建数据卷**：`docker compose down -v`（会清空数据）再 `up`。

---

## 更简单的替代：宝塔面板（可选）

如果你不习惯命令行，可以装「宝塔面板」：
1. 服务器执行 `curl -sSO https://download.bt.cn/install/install_panel.sh && bash install_panel.sh`。
2. 装完会给你一个网页地址 + 账号密码，浏览器登录。
3. 在面板里：装 **Docker** → 用「文件」上传项目 → 「终端」里跑 `docker compose up -d --build`。
