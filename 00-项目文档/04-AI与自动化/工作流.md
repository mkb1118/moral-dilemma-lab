## 现有能力

- `E:\其他项目\ai-orchestrator\`：多模型编排，支持 router、cascade、debate、pipeline、parallel
- `E:\其他项目\scripts\report\`：人格报告生成
- `E:\其他项目\scripts\ppt\`：PPT 生成
- `E:\其他项目\scripts\doc\`：Word 和文档生成
- `E:\其他项目\AI接入指南.md`：多模型接入说明

## 推荐工作流

### 新建测试模块

1. 参考现有 6 个模块的 `data/*.json` 结构
2. 让 agent 先产出题目 JSON 和维度说明
3. 生成 `index.html`，遵循 [[Circuit-Elegance]]
4. 按 [[QA检查清单]] 验收
5. 在 [[人格测试广场]] 登记模块

### 生成人格报告

1. 输入：用户答题结果 JSON
2. 调用 `E:\其他项目\scripts\report\`
3. 输出：Markdown / Word / PPT
4. 统一使用 [[题目与数据结构]] 中的维度定义

## 规则

- 工作流要固定输入、步骤、输出路径
- 每次生成后登记到 [[决策记录]]
