# 心理测试广场 · 云端部署指南

本项目是「一个 Node 服务同时托管 API + 前端页面」，因此云部署只需部署 **这一套东西**，不用拆前后端。

已为你准备好的文件：

- `Dockerfile` —— 容器镜像（Fly.io / Railway / 任意 VPS 通用）
- `.dockerignore` —— 排除敏感/无关文件
- `render.yaml` —— Render 一键部署蓝图
- `server/.env.example` —— 环境变量模板

---

## 方式 A：Render 蓝图（最省事，推荐）

1. 注册 [render.com](https://render.com)（可用 GitHub 账号登录）。
2. 把本项目推到 GitHub（见下方「推送到 GitHub」）。
3. Render 控制台 → **New +** → **Blueprint** → 连接你的 GitHub → 选仓库。
4. Render 自动读取 `render.yaml`，创建：
   - PostgreSQL 数据库 `psychlab-db`
   - Web 服务 `psychlab`（自动执行 `npm install` → `prisma migrate deploy` → `seed` → 启动）
5. 等部署完成，点服务上方的公网链接（形如 `https://psychlab.onrender.com`），发给别人即可。

> 首次部署数据库会「冷启动」几秒，属正常现象。

---

## 方式 B：Docker（Fly.io / Railway / VPS 通用）

构建并运行镜像（在项目根目录执行）：

```bash
docker build -t psychlab .
docker run -d --name psychlab -p 3000:3000 \
  -e DATABASE_URL="postgresql://user:pass@你的数据库地址:5432/psychlab" \
  -e JWT_SECRET="一个强随机长字符串" \
  psychlab
```

镜像启动时会自动执行 `prisma migrate deploy` + `seed`（都是幂等的，重启安全），再启动服务。

### Fly.io 示例

```bash
flyctl launch          # 会读取 Dockerfile，生成 fly.toml
flyctl postgres create # 创建 Postgres，记下连接串
flyctl secrets set DATABASE_URL="..." JWT_SECRET="..."
flyctl deploy
```

## 推送到 GitHub

```bash
cd "E:\my project"
git add .
git commit -m "psychlab 云部署：Dockerfile + render.yaml + CORS 同源放行"
git remote add origin https://github.com/你的用户名/psychlab.git   # 首次
git push -u origin master
```

> `.gitignore` 已排除 `node_modules`、`.env`、`.obsidian`、`ai-orchestrator` 等无关内容，数据库密码不会上传。

## 需要的环境变量

| 变量 | 说明 |
|---|---|
| `DATABASE_URL` | 云 Postgres 连接串（Render 蓝图会自动注入） |
| `JWT_SECRET` | 强随机字符串（Render 蓝图用 `generateValue` 自动生成） |
| `PORT` | 平台自动注入，无需手动设（代码已兼容 `process.env.PORT`） |
| `CORS_ORIGIN` | 同源部署**无需配置**（已改为自动放行同源）；只有前后端分离、跨域访问时才需要填 |

## 部署后自检

1. 打开 `https://你的域名/api/health` → 应返回 `{"status":"ok"}`。
2. 打开 `https://你的域名/api/tests` → 应返回 6 个测试的 ID。
3. 打开首页 → 注册一个账号 → 能正常进入测试并保存历史。

---

## 注意事项

- **数据库密码**：本地 `.env` 里的密码曾在对话中出现过，云上请用全新随机密码。
- **题目数据公开**：`/api/tests/*` 是公开读取的；会话/历史/结果需要登录（JWT）。
- **AI 功能**：`assets/ai-client.js` 默认指向 `http://127.0.0.1:8010`（另一个独立 AI 编排服务），心理测试不依赖它，上云可先忽略。
