# 题目与数据结构

## 通用规范

- 数据统一放在各模块的 `data/` 目录
- 使用 UTF-8 JSON
- 题目 `id` 唯一
- 中文文案为主，字段名保持英文

## 大五人格

- `all-questions.json`：`id, trait, sub, text, key, reverse`
- `pro-extra.json`：结构相同，专业版补充题
- `light-indices.json`：轻量指标数组

## 认知偏差

- `scenarios.json`：`id, bias, biasKey, text, opts[{ text, score }]`
- `bias-info.json`：`key -> { name, icon, ref, desc, fix }`

## 决策风格

- `questions.json`：`id, text, opts[{ text, points }]`
- 维度：`rational`、`intuitive`、`dependent`

## 情绪智力

- `base-questions.json`：`id, dim, sub, type, text, reverse`
- `pro-questions.json`：`id, tag, type, text, opts[{ text, trigger, score }]`
- `dim-info.json`：四个维度及子维度

## 道德困境

- `dilemmas.json`：`id, title, scenario, context, choiceA/B`
- 选择计分：`utilitarian, personal, universal, liberty`
- `archetypes.json`：5 个原型画像

## 价值观排序

- `values.json`：`id, name, icon, short, desc`
- 注意：`values-raw.json` 存在 JSON 解析问题，需要修复。
