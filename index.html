Experiment Index

选择一项心理实验

建议从最想了解的问题开始；所有结果仅用于自我探索。

EXP-001 / MORALITY
🧠

道德困境实验室

8/12题 · 3–6分钟 · 轻量/专业

电车难题、善意谎言、自由与安全——在没有标准答案的情境中，看见你的道德判断模式。

结果包含：道德画像、困境倾向、哲学理论映射。
EXP-002 / PERSONALITY
🌊

大五人格评测

25/55题 · 4–9分钟 · 轻量/专业

基于 OCEAN 模型，从开放性、尽责性、外向性、宜人性、情绪稳定性描绘人格全貌。

结果包含：五维图谱、人格组合、关系与职业建议。
EXP-003 / COGNITION
🔍

认知偏差检测

36题 · 5–7分钟 · 情境判断

确认偏误、锚定效应、可得性启发……测测哪些看不见的思维捷径正在影响你。

结果包含：偏差抵抗力、12类偏差图谱、觉察建议。
EXP-004 / EMOTION
🎭

情绪智力评估

24/54题 · 5–12分钟 · 轻量/专业

识别、理解、运用和管理情绪——看见你在自我觉察、共情和调节策略上的能力结构。

结果包含：EQ总分、四维能力、触发地图与成长路径。
EXP-005 / DECISION
🎯

决策风格分析

25题 · 4–6分钟 · GDMS框架

你是直觉型还是分析型？快速决断还是深思熟虑？了解你的决策 DNA。

结果包含：主导风格、优势盲区、场景策略。
EXP-006 / VALUES
🧭

核心价值观排序

12项排序 · 约3分钟 · Schwartz框架

安全、自由、成就、关系、意义……当价值冲突时，看见自己真正的优先级。

结果包含：价值罗盘、冲突地图、决策指南。
